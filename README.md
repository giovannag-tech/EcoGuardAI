# 🌱 EcoGuard AI

Sistema inteligente de monitoramento ambiental para agricultura utilizando Inteligência Artificial, Machine Learning, PostgreSQL, Visão Computacional e Dashboard Interativo.

## 🚀 Tecnologias Utilizadas

- Python
- PostgreSQL
- Pandas
- Scikit-Learn
- Streamlit
- OpenCV
- Git e GitHub
